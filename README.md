# PhotonQ

**PhotonQ** — проект, направленный на разработку доступного инструмента для оценки качества нанофотонных структур с применением технологий глубокого обучения и плазмон-индуцированной радикальной полимеризации.  
Данная работа выполнена при поддержке программы исследовательских проектов в области искусственного интеллекта Университета ИТМО (НИРсИИ) №640098.

В дальнейшем интеграция текущих (за 1 и 2 этап) и последующих результатов (за 3 этап) позволит сформировать комплексный подход, обеспечивающий количественную оценку усиления электромагнитного поля образца на основе
спектральных характеристик его поглощения.

---
## Идея проекта

- Нанофотонные структуры, в частности плазмонные наноструктуры, используются для датчиков, фотонных чипов и передовых наноустройств. Ключевым параметром для оценки производительности этих систем является коэффициент усиления электромагнитного поля, который зависит от геометрии и взаимодействия наночастиц.

- Уникальное взаимное расположение и одновременное взаимодействие множества групп наночастиц между друг другом и между группами усложняет получение оценки производительности и качества подобной структуры, требуя значительных вычислительных ресурсов для предсказания коэффициента усиления электромагнитного поля.

- Данный проект нацелен на решение ряда проблем, которые препятствуют внедрению автоматического контроля качества плазмонных структур. Предлагается использование модели Pix2Pix GAN для предсказания карты распределения усиления электромагнитного поля вблизи плазмонных структур.

# 1 этап (предсказание распределения полимера с помощью Pix2Pix GAN)

- Задача сводится к image-to-image translation (предсказать изображение “частицы и полимер” по входному изображению “частицы”). Исходные данный - SAM изображения частиц с полимером. Однако возникает проблема: физически невозможно сделать снимок частиц, а потом снимок их же с полимером в одном и том же месте. Так как после получения снимка частиц до полимеризации образец модифицируется под действием электронного пучка.

- Однако было найдено решение – настройка контраста изображения частиц с полимером для получения обработанного снимка, на котором видны лишь частицы.  

- Таким образом, получены соответствующие пары для сэмпла датасета, однако основная цель - предсказание именно распределения полимера. Поэтому для упрощения генерации моделями (нам не интересно знать лишние детали фона образца и локальные особенности) были сформированы бинарные маски полученных изображений. Использовалась библиотека OpenCV для формирования бинарных масок на основе выделения порога.


## Особенности SEM-изображений частиц

- Изображение с электронного микроскопа получается в огромном разрешение (часто больше 10 000 на 10 000 пикселей). Пришла идея делить такие огромные изображения на патчи. Но это надо делать корректно. Для этого мы использовали автокорреляционную функцию, которая показала “правило”, как необходимо делить исходное изображение на патчи.

- Соответственно, результирующий датасет состоит из 1320 пар изображений, которые изначально были получены из 10 исходных (15×15 мкм) изображений одного масштаба путем деления с помощью автокорреляционной функции и аугментации в виде поворотов на ±90° и 180°

## Результаты

- Был л обучен Pix2Pix GAN (генератор на основе U-Net, а дискриминатор PatchGAN). В качестве Input - бинарные маски изображения частиц, Target - бинарные маски изображений частиц с полимером. # 2 этап (Conditional Pix2Pix для моделирования распределения полимера)

-  Pix2Pix (cGAN) предсказывает распределение полимера вокруг частиц в зависимости от заданного расстояния. Модель обучается на парах изображений: входные частицы (input) и соответствующие бинарные маски полимера (target), сгруппированные по папкам расстояний.

## Данные 
- Исходные изображения нарезаются **скользящим окном** на патчи фиксированного размера (например, 512×512). 
- Для **каждого** расстояния таким образом получено **816 кадров** (пар input/target).
- Всего используется **15 различных расстояний**, каждое из которых соответствует отдельному уровню роста полимерного слоя.
